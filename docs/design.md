# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 考え

**この画面は、AI の工場の「作業日報」を、生成りの紙に組版した物に見える。**
大きな日本語で「1行の Issue から、AI が作って、公開まで回す。」と言い切り、その隣で工場の時刻ログが1行ずつ進む。下へ進むと、工場が実際に作った画面（本物のブラウザで撮った画像）が、紙面いっぱいに1枚ずつ載る。飾りは足さず、文字の大きさの差・罫・余白・作品の画像だけで見せる。3D は使わない。

## 参考にした実例（撮った画像は `factory-refs/shots/`、まとめは `factory-refs/board.md`）

- Toshiyuki Hashimoto https://toshiyukihashimoto.jp/ — 巨大な文字と小さな文字の差だけで作る一画面。カンマ区切りの文のナビ。2行目だけ段をずらす見出し
- Maksym Bleibtgleich https://bleibtgleich.dev/ — 1本の黒い縦罫を背骨にしたグリッド。薄いグレーの巨大な文字で奥行き
- Tomoya Okada v7 https://v7.usestate.org/ — 最初の画面の隅に、作品への入口のカードを置く
- This.design https://this.design/ — 画像が主役。角を小さく丸め、文字は画像の邪魔をしない
- Nick Clement https://nickclement.com/ — 左 3 割は見出し、右 7 割は中身。1px の罫で段を区切る
- TAIKI SATO https://taikisato.com/ — 英字の大見出しに日本語を添える組み方
- TAKAFUMI SENDA https://takafumisenda.com/ — 白でなく生成りの紙の地
- Yusuke Fukunaga https://yusukefukunaga.com/ — 開発者の作品は「画面そのもの」が写真になる

## 文字

- 日本語：Zen Kaku Gothic New（`next/font/google`、400 / 500 / 700）。本文 15px、行間 1.9
- 英字・数字の見出し：Geist（500〜600）。字間 -0.03〜-0.07em、行間 0.8〜0.95
- 時刻・ラベル・URL：Geist Mono 12〜13px、字間 0.04em、大文字。日本語が入ったら Zen Kaku Gothic New で出る
- 大きさ
  - 最初の画面の見出し：`clamp(39px, min(7.6vw, 12.5svh), 140px)`、500、行間 1.12、`palt` を効かせる。3行で、2行目だけ 1 字下げる
  - 「Works」の飾り見出し：`clamp(88px, 19vw, 300px)`
  - 作品の名前：`clamp(40px, 6.4vw, 104px)`、作品の番号：`clamp(56px, 7vw, 112px)`
  - 段の見出し（できること・わたし）：22px、500
  - 「わたし」の一言：`clamp(26px, 3.4vw, 48px)`、500
  - 本文の最小は 15px、補足の最小は 12px（ラベルだけ）

## グリッドと余白

- 900px 以上：12 列、外の余白 40px、列の間 24px。左 3 列が「見出しの列」（番号・種類・段の名前）、右 9 列が「中身の列」
- 900px 未満：1 列、外の余白 20px、列の間 20px
- 段と段の間：160px（900px 未満は 96px）。段の頭に墨の 1px の罫を外の余白の内側いっぱいに引き、罫から 28px 下に中身
- 最初の画面だけ、中身の列の左に墨の 1px の縦罫（背骨）
- 本文の幅は 34em まで

## 部品

- **頭の帯**：高さ 64px、上に貼り付き、紙の 88% と後ろのぼかし。左に「Gaku1205」（Geist 600 18px）、右に「作品, できること, わたし, GitHub」をカンマ区切りの文で。600px 未満は「作品, GitHub」だけ。押せる高さ 44px
- **作業ログ（RunLog）**：上に墨の 1px、頭の行に印の丸い点・題・今の時刻。行は「時刻 / 人か AI / 何をしているか」の3列で、行の間に薄灰の罫。今の行は太字で、時刻の左に印の四角（6px）。まだの行は灰。下に 2px の進み具合の帯と「実際に回った1回の記録」（Gaku1205/atelier-journal の Issue #1 → PR #2 の時刻。記録元は src/lib/pipeline.ts の冒頭に書く）。工場の図では墨の地の上に、色を反転して大きめ（14〜15px）で組む
- **最初の画面のカード**：墨の 1px 枠、角 4px、内側 10px。左に作品の画像（152px、スマホは 112px）、右に「番号 / 種類」・名前（Geist 20px）・1行の説明、右端に「↓」。その作品の段へ飛ぶ
- **目次**：上に墨の罫。番号（mono）・名前（Geist 20px）・種類（灰 13px）の行を、900px 以上は 2 列で。行の高さは 44px 以上
- **作品の段**：左の列に大きな番号と種類（900px 以上は画面の上に貼り付く）。右の列に名前・日本語の名前・1行の説明、その下に図、その下に「何か」「どう作ったか」と、「使った物」のタグ・リンクの行
- **受賞の文字（`award`）**：作品の段の名前の上に、既存の「ラベル」の書式（Geist Mono 12〜13px、灰。日本語は Zen Kaku Gothic New）で「AWS デジタル社会実現ツアー2025 九州 最優秀賞」を1行（狭い幅では折り返す）出す。名前との間は 12px。賞のロゴ・印の色は使わない。目次・最初の画面のカードの種類の欄は「受賞作」
- **追加の画像（`extras`）**：作品の図（PC＋スマホ）の下に、間 24px で、PC の画像と同じ幅のブラウザの枠に入れて1枚ずつ置く（めぐりモノの出品一覧、1440×900。スマホ版は無い）。画像の上に文字は重ねない
- **ブラウザの枠**：PC の画像（1440×900）を入れる窓。CSS だけで作る（枠の素材画像は使わない）。外側は薄灰 1px の枠・角 4px・下に柔らかい影（`0 24px 48px -32px`、墨の 30%）。上に高さ 32px のバー（紙の地、下に薄灰 1px の罫）。バーの左に丸 3つ（直径 8px、薄灰、間 6px）、その右にアドレス（高さ 20px、薄灰 1px 枠、角まる 999px、Geist Mono 12px・字間 0.04em・灰、はみ出したら「…」）。アドレスにはその作品の公開ページの URL（`https://` 無し）を出す。公開ページが無い作品（めぐりモノ）は GitHub の URL。バーは読み上げない。画像はバーの下にいっぱいに入れる。窓の中の画像の地は `#E6E2DA`（画像が出るまで）
- **スマホの輪郭**：スマホの画像（390×844）を入れる輪郭。CSS だけで作り、実在の機種には似せない。本体は墨の地・角 20px・縁（画像との間）5px・外に墨 1px の線・下に柔らかい影（`0 24px 48px -24px`、墨の 45%）。画面は角 15px。上の中央に小さな切り欠き（本体の幅の 28%、縦横比 5:1、墨、下の角だけ 8px）を画像に重ねる（文字ではない）
- **作品の図**：PC の画像（1440×900）をブラウザの枠に入れて中身の列いっぱいに置く。スマホの画像（390×844）をスマホの輪郭に入れ、PC の窓の右下に手前から少しかぶせる（右から 3%、幅 19%・最小 82px、下は窓の下の余白 6% に出す）。狭い幅（390px）でも同じ重ね方で、枠も画像もはみ出さない。画面を持たない仕組み（工場）は、墨の地に作業ログと「この工場が作った物」の画像を並べる。スマホの画面が無い作品（ゲーム）は、PC のブラウザの枠だけを中身の列いっぱいに置く（スマホをかぶせない。下の余白 6% も付けない）。アドレスは公開ページが無いので GitHub の URL
- **作品の詳しいページ（`/works/[id]`）**：頭の帯（「作品」は `/` の作品の段へ戻る）、「トップに戻る」、作品の段（番号・種類・名前・説明・何か・どう作ったか・使った物・リンク）、画面の列、「トップに戻る」、終わりの帯の順。既存のグリッド（900px 以上は左 3 列が見出し、右 9 列が中身）に載せ、段の頭の墨の罫・色・文字・動きは作品の段と同じ。新しい色・文字・形は足さない
  - **「トップに戻る」**：Geist Mono 12px の大文字ラベルの寸法で「← トップに戻る」（日本語は Zen Kaku Gothic New 15px）。押せる高さ 44px、下線は押したときだけ。頭の帯の下、墨の罫の上に置く
  - **「画面をもっと見る」「進み方を詳しく見る」**：作品の段のリンクの行の先頭に、リンクの行（高さ 52px 以上・「公開ページ」と同じ作り）で置く。文字は太字 15px、右端は「→」（Geist 18px。押すと右に 3px 動く）。同じタブで開くので「新しいタブで開く」は付けない
  - **画面の列**：見出し「スクロールした画面」（段の見出しと同じ 22px・500）の下に、PC の画像をブラウザの枠に入れて縦に並べる（間 40px、中身の列いっぱい、画像は 1440×900 のまま）。1枚の下にラベル「PC 1 / 4」（mono 12px、灰）。そのあとに見出し「スマホ」、スマホの画像（390×844）をスマホの輪郭に入れて、900px 以上は 4 列、900px 未満は 2 列で並べる（間は列の間と同じ）。下にラベル「SP 1 / 4」。画面の列の頭には墨の 1px の罫を引き、罫から 28px 下に中身
  - スマホの画面が無く、スクロールした画面も無い作品（ゲーム）：画面の列の位置に、見出しを足さず、画面の列と同じ頭の罫（墨の 1px、罫から 28px 下）の下へ、追加の画像を間 24px で縦に並べる。1枚ずつ PC と同じ幅のブラウザの枠（1440×900、アドレスは GitHub の URL）。ラベルの番号は付けない。「スクロールした画面」「スマホ」の見出しは出さない。新しい色・文字・形は足さない
  - 画面を持たない仕組み：作品の図（墨の地の作業ログと「この工場が作った物」）をそのまま使い、画面の列は出さない
  - 作品の画像が入ると 0.8 秒で出る動き（既存）を、画面の列の画像1枚ごとに使う
- **技術のタグ**：13px、薄灰 1px 枠、角まる（999px）
- **リンクの行**：上下に罫、高さ 52px 以上。「公開ページ」「GitHub」（太字 15px）・短い URL（mono 灰）・「↗」。押すと新しいタブで開き、読み上げには「（新しいタブで開く）」
- **終わりの帯**：墨の地。「github.com/Gaku1205 ↗」を Geist で大きく、その下に画面幅いっぱいの影の「Gaku1205」、最後に「© 2026 Gaku1205 — Fukuoka」
- フォーカスは墨（墨の地では紙）の 2px の枠、3px 離す

## 動き

- 読み込み時：最初の画面の見出しの3行が、下から 24px・0.9 秒で立ち上がる（0.08 秒ずつずらす）
- 作業ログ：1.2 秒ごとに次の行へ。最後の行で 3.2 秒止まって最初に戻る。印の丸い点は 1.2 秒で明滅
- 作品の図：画面に入ると 0.8 秒で、透明から 16px 上がりながら出る
- 押せる物：「↗」が右上に 3px 動く、画像が 4px 上がる、カードの地が少し暗くなる
- `prefers-reduced-motion`：動きを全部止め、ログは全部の行を点灯、進み具合の帯はいっぱいにする

## 写真（作品の画像）の扱い

- 作品の画像は、公開ページを本物のブラウザで撮った物だけを使う：`node .github/scripts/shot.mjs --scale 2 --format webp --out public/works --widths 1440,390 <公開ページの URL>`（2倍の細かさの webp。高精細な画面でもぼやけない。png は使わない）。画面の前に操作が要るときは `--steps`（agent-desk はデモのページを開いてから撮った）
- 詳しいページ用の「スクロールした画面」は `--scrolls 4` を付けて撮る（1 作品・1 幅あたり原則 4 枚。デモが短く撮れない作品は撮れた分だけ出す。agent-desk は PC 2枚・スマホ 3枚。名前は `<名前>-<幅>-s<番号>.webp`）。agent-desk は同じデモの操作の後で撮る
- 画像は、PC はブラウザの枠、スマホはスマホの輪郭に入れて見せる（上の部品）。画像そのものには枠を焼き込まない
- 加工しない（色を変えない・切り抜かない）。PC の画像は 16:10 のまま
- 文字の画像は使わない。ストックの写真も使わない

## 作品を足すとき

- `src/lib/works.ts` の `WORKS` に1つ足すだけで、目次・作品の段・番号が増える。画面を持つ作品は `figure: { type: "shots", ... }`、画面を持たない仕組みは `figure: { type: "pipeline", outputs: [...] }`
- 追加の画像は `shots.extras: [{ src, alt }]`（PC のみ、図の下に並ぶ）。受賞作は `award: "受賞の文字"` を書き、`kind` は「受賞作」にする。並びは `WORKS` の順なので、受賞作は先頭に置く
- スマホの画面が無い作品（ゲームなど）は `shots.mobile` を書かなくてよい（スマホの輪郭は出ない）。`scrolled` は空にし、追加の画像は `extras` に入れる（詳しいページに出る）
- 文言は「何か」「どう作ったか」を1〜3文ずつ、です・ます無しの言い切りで

## 避けること

- 色を増やす・グラデーション・光る効果・3D
- 角の大きな丸み（ブラウザの窓は 4px、スマホの輪郭だけ本体 20px・画面 15px）
- 実在の機種そっくりの輪郭（ノッチの形・ボタンなど）、枠の素材画像
- 画像の上に文字を重ねる
- 実在のブランドの名前・ロゴ。本名・学校名・連絡先（連絡は GitHub だけ）
